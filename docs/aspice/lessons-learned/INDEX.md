# ASPICE Lessons Learned

This folder stores one lessons-learned file per ASPICE review topic when a HITL
review comment requires follow-up.

Naming convention:

- `QA-<topic>.md` for quality assurance topics.
- `VER-<topic>.md` for verification topics.
- `SYS-<topic>.md`, `SWE-<topic>.md`, or `SUP-<topic>.md` for process-specific topics.

Each file should record the triggering review comment, decision, rationale,
evidence links, and any process update needed to prevent recurrence.
