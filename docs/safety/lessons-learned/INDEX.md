# Safety Lessons Learned

This folder stores one lessons-learned file per safety goal or safety review
topic when a HITL review comment requires follow-up.

Naming convention:

- `SG-NNN-<short-title>.md` for safety-goal-specific topics.
- `SAF-<topic>.md` for cross-cutting safety process, timing, analysis, or validation topics.

Each file should record the triggering review comment, decision, rationale,
evidence links, and any safety-plan or safety-case update needed to prevent
recurrence.
